## 📌 Project Overview
This repository contains a comprehensive collection of **Fundamentals of Machine Learning (FOML)** lab experiments. It covers essential machine learning algorithms, ranging from basic data preprocessing and linear models to advanced topics like support vector machines, ensemble methods, and convolutional neural networks (CNNs).

The experiments are designed to build a strong foundation in machine learning and deep learning using industry-standard libraries such as `pandas`, `numpy`, `scikit-learn`, and `TensorFlow/Keras`.

## 🛠️ Usage & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mukilan-s18/Fundamentals-of-Machine-Leanings-Experiments.git
   cd Fundamentals-of-Machine-Leanings-Experiments
   ```

2. **Set up the environment:**
   Ensure you have Python installed along with the required libraries. You can install them using pip:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn mlxtend tensorflow
   ```

3. **Execute the scripts:**
   To run an experiment, simply execute the respective Python script in your terminal:
   ```bash
   python FOML-Exp-1
   ```
